Reconocimiento de comandos de voz

Inteligencia artificial

Modelo de inteligencia artificial que reconoce comandos de voz.

  • TensorFlow
  • seaborn
  • NumPy
  • Matplotlib

Descripción detallada

Este sistema implementa redes neuronales utilizando TensorFlow para procesar espectrogramas de audio y clasificar comandos vocales en tiempo real. Incluye un flujo completo de procesamiento de datos con NumPy, generación de métricas de precisión y matrices de confusión detalladas mediante Matplotlib y Seaborn.

Gestión de almacén de refacciones

Base de datos

Aplicación que administra un almacén de refacciones, con interfaz gráfica de usuario, manejo de excepciones y operaciones CRUD sobre una base de datos SQL.

  • SQL
  • Interfaz gráfica
  • CRUD
  • Manejo de excepciones

Descripción detallada

Desarrollo de un sistema integral de control de inventarios diseñado para gestionar entradas, salidas, stock mínimo y proveedores. La aplicación se conecta mediante JDBC/SQL a una base de datos relacional robusta, con control estricto de transacciones y un módulo integral de manejo de excepciones para garantizar la integridad de los datos.

Réplica de Doodle Jump

Videojuego

Réplica del juego construida con el patrón Modelo-Vista-Controlador y programación orientada a objetos, con clases para las plataformas, los enemigos, el jugador y los poderes.

  • MVC
  • POO
